# Repository instructions

- `README.md` is the Chinese GitHub homepage. `README.en.md` is its English counterpart.
- Whenever either README changes, update both in the same commit. Keep section order, project status, links, commands, and factual claims aligned across languages.
- Describe only implemented behavior as available; keep planned features clearly marked as pending in both languages.
- Do not commit downloaded textbook Markdown, generated indexes, caches, or credentials.
