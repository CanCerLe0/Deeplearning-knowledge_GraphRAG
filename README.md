# Bilingual Graph RAG for Deep Learning

This repository is being initialized for a local, bilingual graph-enhanced RAG experiment based on selected Markdown chapters from *Dive into Deep Learning*.

The implementation plan is in [docs/图谱增强RAG实施计划.md](docs/图谱增强RAG实施计划.md). The [design](docs/图谱增强RAG项目设计草案.md) and [bilingual supplement](docs/superpowers/specs/2026-11-15-bilingual-local-markdown-rag-design.md) define the research question and data workflow.

The repository currently contains project documents, package scaffolding, and original bilingual sample text. The ingestion, indexing, retrieval, graph, generation, and evaluation commands are planned but not yet implemented. Third-party textbook files and generated indexes will stay local and are excluded from Git.
