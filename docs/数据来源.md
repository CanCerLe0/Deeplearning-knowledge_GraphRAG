# 第一版语料来源

本项目使用《动手学深度学习》两个上游仓库的 Markdown 原文，在本地构建检索语料。具体文件、标题、语言与逐文件 SHA256 记录在 [`config/sources.yaml`](../config/sources.yaml)。本地下载结果位于 `data/raw/`，该目录被 Git 忽略，不随本仓库发布。

| 语言 | 上游仓库 | 固定提交 | 文件数 | 本地目录 |
|---|---|---|---:|---|
| 中文 | [`d2l-ai/d2l-zh`](https://github.com/d2l-ai/d2l-zh) | `e6b18ccea71451a55fcd861d7b96fddf2587b09a` | 14 | `data/raw/d2l-zh/` |
| 英文 | [`d2l-ai/d2l-en`](https://github.com/d2l-ai/d2l-en) | `23d7a5aecceee57d1292c56e90cce307f183bb0a` | 14 | `data/raw/d2l-en/` |

选取范围为序列模型、编码器—解码器与序列到序列、注意力机制及 Transformer 的相关小节。中文和英文按主题选取，不假定文件或段落严格一一对应。中文仓库的 `*_origin.md` 翻译原稿副本未纳入，避免重复入库。

教材正文、由其构建的全文索引和缓存只保留在本地。项目代码的 MIT 许可不覆盖教材文本；复用或再分发前须核查上述固定提交中各仓库的许可与署名要求。

## 概念图的来源与审核

`build-graph` 读取已校验入库的 `chunks.jsonl`，按语言和小节请求结构化关系候选。只有四种允许的关系、`0–1` 的有限置信度、且证据 ID 属于当前请求批次的边会进入图；拒绝原因及数量写入本地 `graph_manifest.json`。图中的每条边都指向原文片段，片段保留语言、原文位置及固定版本链接。抽取提示词版本和模型标识也记录在该清单中。API 的逐批输出缓存在 `data/index/graph/cache/`，相同输入重复构建不会再次请求；缓存与图索引均被 Git 忽略。

跨语言概念名只按 [`config/concept_aliases.yaml`](../config/concept_aliases.yaml) 中的审核记录归一。每条记录列出标准名、别名、两个不同语言的原文片段 ID 与核查依据；构建时校验名称确实出现在对应片段。现有两组别名来自项目自写的双语示例，另四组来自固定版本教材的术语和上下文核对；作者仍可进一步人工复核。别名归一不会合并片段 ID，也不会把图边作为回答证据。

本地构图命令：

```bash
python -m kgrag.cli build-graph --chunks data/index/chunks.jsonl --out-dir data/index/graph --aliases config/concept_aliases.yaml --reviews config/graph_reviews.yaml --max-output-tokens 2048
```

此命令需要可用的 DeepSeek 兼容 API 密钥；首次抽取还需要网络。相同输入与模型配置的再次构建使用本地抽取缓存，不重复请求。运行后可从 `data/index/graph/graph.json` 检查有效边，从 `graph_manifest.json` 查看来源提交、模型、提示词版本、结构拒绝数及逐条审核排除数。审核结果和限制见 [图谱抽取抽查](./图谱抽取抽查.md)。

本地流程检查选取两个固定版本教材片段及四个自写示例片段，用人工编写的假客户端提供两条关系，重载后得到一条带两个不同教材片段 ID 的跨语言两跳路径，并在清单中看到两个仓库的提交。无网络测试还覆盖非法关系类型、越批次或不存在的证据 ID、非有限置信度及未经审核的别名。该流程检查与真实 API 抽取的审核结果分开记录。
