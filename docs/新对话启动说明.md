# 图谱增强 RAG 项目：新对话启动说明

本文件与设计草案、实施计划和双语设计补充均位于 `docs/`。实施计划中的代码路径以 `docs/` 的上一级项目文件夹为仓库根目录；文档间的链接为相对路径。

## 已确定的要求

- 目标是展示人工智能算法能力，用于申请人工智能实习岗位。
- 方法主线是图谱增强的多跳检索，并与纯向量 RAG 做公平对照和消融。
- 时间为 1–2 周，每天投入 3–4 小时；第 7 天形成可运行版本，第 14 天完成评测与公开发布。
- 可使用本地 GPU 和付费 API（例如 DeepSeek）；分片、索引、召回、图扩展和重排在本地完成，大模型可以外接。
- 第一版从《动手学深度学习》中英文 GitHub 仓库分别下载固定版本的 Markdown，在本地校验和入库；中文问题可引用英文原文。
- 知识库支持增加本地 Markdown：只改来源清单并重建索引，不修改检索算法。
- 最终代码发布到项目作者本人账号下的 GitHub 公开仓库。
- 设计稿已获确认；实施计划已写好，但项目代码和 GitHub 仓库尚未创建。

## 交接注意点

1. 公开仓库应有 README、代码许可、来源说明、复现命令、实验结果与演示材料。不得提交真实密钥、`.env`、第三方教材正文或全文索引。
2. 中文教材仓库与英文版教材的许可说明不同。方案采用公开来源与获取脚本，不随代码仓库再发布第三方教材正文；如需改变这一点，应先核对所用版本的许可。
3. 当前计划中 12 道开发题用于调参，36 道测试题在参数固定后运行；第一周开发集结果不能当成最终效果结论。
4. GitHub 仓库名、具体 GPU 型号和 API 支出上限尚未确定；它们可在实际实施时按环境选择，不改变已确认的研究主线。
