## 开发集检索初评

2026-11-24 的开发集运行使用固定版本双语索引和 `data/eval/dev.jsonl`。10 道可回答题共有 15 个必需证据组；另外 2 道不可回答题不计入证据召回分母。以下数字用于调试和初评，不代表封存测试集效果。答案正确率与引用支持率尚无完整人工评分。

| 检索模式 | 必需证据组命中 / 15 | 完整证据命中 / 10 题 | Top-5 含英文片段 / 12 题 |
| --- | ---: | ---: | ---: |
| `dense` | 15 | 10 | 5 |
| `one_hop` | 15 | 10 | 5 |
| `typed_path` | 11 | 6 | 10 |

“命中”指 Top-5 中至少有一个片段 ID 落入同一论点的候选证据组。“完整证据命中”要求一道题的所有必需组均命中。英文片段计数仅表示进入上下文，不表示答案引用了英文。三种模式共用 555 个片段的双语索引、`BAAI/bge-m3` 模型版本 `5617a9f61b028005a4858fdac845db406aefb181`、本地图索引、`config/retrieval.yaml`、Top-5 和 3000 的近似消息 token 预算；运行设备为 CPU。

[逐题检索轨迹](../data/eval/dev_retrieval_trace.json)只保存 Top-5 片段 ID、英文片段 ID、逐组命中布尔值和运行配置，不含教材正文。题集 SHA256 为 `7830a7b00582fe336dbab61b9b001e339a5ec37b155fc22c1fbfa0e5f7193499`，向量索引指纹为 `65151e53aca9941c923c73334ee00d56364c3b26128760071cd015423330df9b`，图边与审核状态指纹为 `7b637f1f987421d69f9d462f2e613f34ad467fce20e78d6c197ec5632571ed60`。下载、校验、入库并构建索引和图谱后，可用以下命令复核；重新抽取或审核图边会改变图指纹，需要重新统计：

`dev-01` 的候选证据组包含自写查询、键和值示例片段；`dev-09` 的证据组包含说明束宽为 1 时等同贪心搜索的中文片段。`dev-11` 和 `dev-12` 分别询问位置编码改动后及束宽为 7 时的确切 BLEU 结果；固定双语语料包含方法说明，但未提供这些实验数值。`typed_path` 使更多英文片段进入 Top-5，同时在 `dev-02`、`dev-03`、`dev-10` 等题挤掉所需证据，因此英文片段数量不能单独代表检索质量。参数调整仅使用开发题；正式比较须使用封存后的测试集。

## 消融与失败案例

两项消融均在相同的 60 题、索引、生成模型与提示词上运行 `typed_path`。`β=0` 仅将 `path_weight` 从 0.5 改为 0；图扩展与覆盖项仍保留。“关闭类型”仅将 `use_relation_types` 从 `true` 改为 `false`。

| 配置 | Recall@5 | 完整证据命中率 | 多跳完整召回率 | 相对主配置的 Top-5 排名列表变化题数 | 平均延迟 | API 总 token |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 主配置 | 37.0% | 26.0% | 19.2% | — | 1.82 秒 | 143,247 |
| `β=0` | 67.0% | 54.0% | 42.3% | 44 | 2.02 秒 | 147,627 |
| 关闭类型权重 | 37.0% | 26.0% | 19.2% | 9 | 1.92 秒 | 142,953 |

“排名列表变化”包含只改变顺序的题目；若只比较 Top-5 片段 ID 集合，`β=0` 与关闭类型权重分别改变了 27 题和 3 题。

`test-01`（掩蔽 softmax）中，`dense` 的 Top-5 命中所需证据，`typed_path` 的 4 条结果均带图路径，却没有命中；排在前列的是困惑度、编码器—解码器等其他章节片段。`test-44`（Bahdanau 注意力与训练速度）中，`dense` 命中两个必需证据组，`typed_path` 的 Top-5 全是带路径片段，两个组均未命中。两例均显示路径候选占据了有限的证据位置；结合 `β=0` 消融，当前路径分对这份题集的证据检索不利。`typed_path` 在 46 题检出中英文片段，高于 `dense` 的 26 题，但其必需证据组召回更低，说明检出英文片段的数量不能代替相关性指标。

## 答案盲评与本地复现材料

主对照生成了 180 条答案，并在被 Git 忽略的 `data/runs/` 生成随机排序的 `test_blind.jsonl` 和单独保存模式映射的 `test_blind_key.jsonl`。盲评表的 180 条 `answer_rating` 均未填写。答案正确率、引用支持率和拒答准确率因此**尚无正式人工评分**，不能从检索命中率或程序的引用 ID 校验推断。评分者须逐条填写 `answer_rating`（0 错误、1 部分正确、2 正确）；有引用时填写 `citation_supported`，不可回答题填写 `refusal_correct`。评分完成后运行：

```bash
python scripts/score_annotations.py score --annotations data/runs/test_blind.jsonl --key data/runs/test_blind_key.jsonl --output data/runs/test_human_summary.json
```

评分汇总将按模式、题型、金标准证据语言和实际检出语言分组，并列出人工标注的失败案例。主运行、两项消融及检索汇总分别保存在 `data/runs/test_main.jsonl`、`test_no_path.jsonl`、`test_no_types.jsonl` 和相应的 `*_retrieval_summary.json`。原始 JSONL 与盲评表含第三方教材片段及生成答案，只保存在本地，不能提交。可用下列固定参数复现；模型服务的输出仍可能随服务端版本变化。

```bash
python -m kgrag.cli eval --questions data/eval/test.jsonl --output data/runs/test_main.jsonl --embedding-revision 5617a9f61b028005a4858fdac845db406aefb181 --device cpu
python -m kgrag.cli eval --questions data/eval/test.jsonl --modes typed_path --ablate-path --output data/runs/test_no_path.jsonl --embedding-revision 5617a9f61b028005a4858fdac845db406aefb181 --device cpu
python -m kgrag.cli eval --questions data/eval/test.jsonl --modes typed_path --ablate-types --output data/runs/test_no_types.jsonl --embedding-revision 5617a9f61b028005a4858fdac845db406aefb181 --device cpu
python scripts/score_annotations.py retrieval --questions data/eval/test.jsonl --results data/runs/test_main.jsonl --output data/runs/test_retrieval_summary.json
python scripts/score_annotations.py retrieval --questions data/eval/test.jsonl --results data/runs/test_no_path.jsonl --output data/runs/test_no_path_retrieval_summary.json
python scripts/score_annotations.py retrieval --questions data/eval/test.jsonl --results data/runs/test_no_types.jsonl --output data/runs/test_no_types_retrieval_summary.json
```

## API 用量与结论边界

三路主对照调用生成接口 180 次，两项消融各 60 次，合计 300 次；输入 671,453 token，其中缓存命中 260,220、未命中 411,233，输出 57,474，总量 728,927。按运行时段适用的 [DeepSeek Flash 高峰价](https://api-docs.deepseek.com/quick_start/pricing/)（每百万输入缓存命中 $0.006、未命中 $0.3、输出 $1.2）估算，本轮主对照与消融约 **$0.194**，不含一次开发题接口预检；实际扣费以服务商账单为准。各条调用返回的实际输入 token 最大为 2,893，未超过本轮 3,000 的近似消息预算。预算选择仍使用项目的近似计数器，尚未接入所选模型的消息模板与 tokenizer；服务端实际 token 用量以 API 返回值为准。

本轮只覆盖固定章节的 60 道已审核题、一个生成模型别名和一份图索引；生成接口返回的是 `deepseek-flash` 别名，服务端底层版本未由运行记录独立锁定。不能据此宣称统计显著或推广至其他语料。题目由助手起草，未满足原定作者独立撰写配额；人工答案评分尚未完成。图边的 40 条分层抽查有 29 条通过、10 条拒绝、1 条待定，另有 47 条活跃边未逐条审核；29/40 仅是抽查通过比例，不能当作全图无偏精度估计，详见[图谱抽取抽查](./图谱抽取抽查.md)。
